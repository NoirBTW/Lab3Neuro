# Набор Insects Commons 116

Задача: классификация фотографии взрослого насекомого между тремя конкретными видами.
Подборка собрана для этой лабораторной работы 07.09.2026 из отдельных открытых файлов Wikimedia Commons.
Это самостоятельный поиск и отбор чужих лицензированных фотографий; личная фотосъёмка не заявляется.
Готовые наборы ImageFolder/Kaggle и данные из отчёта другого студента не использовались.

## Сбор и контроль

`collect_data.py` обращается к MediaWiki API: поиск латинского названия в заголовке, bitmap, два блока по 50 результатов.
Выбираются лицензии CC BY, CC BY-SA, CC0 или Public domain и исходный короткий размер не менее 300 px.
Скачиваются серверные уменьшенные копии по `download_url`; реальные размеры сохранены в sources.csv. Raw означает файлы до локальных аугментаций, не полноразмерные оригиналы фотографов.
Полноразмерный URL и страница источника также сохранены. Название локального файла — уникальный page ID Commons.
По заголовкам отфильтрованы явные рисунки, личинки и музейные экземпляры; 135 кандидатов просмотрены визуально.
Отклонены ещё 19 кандидатов: рисунки, личинки, пустая оболочка, крайние макрофрагменты, слишком мелкие насекомые и неоднозначная сцена.
`candidates.csv` сохраняет метаданные кандидатов, `rejected.csv` — причины отказа, `sources.csv` — 116 принятых фотографий.

Точные повторы проверяются по SHA256 RGB-пикселей с размером изображения. Дополнительно проверен dHash 64 бита, порог Hamming ≤5; близкие пары не обнаружены (`duplicate_review.json`). Этот метод не гарантирует отсутствие всех визуально похожих сцен.
Разделение проводится **по автору**, 68 авторских строк. Фотографии одного автора целиком относятся к train, val или test, включая похожие серии.
Для приближения долей 60/20/20 перебираются 20 000 случайных назначений групп с seed=42, выбирается минимальное отклонение долей при минимуме 15 train и 5 val/test на класс. Содержание и метрики модели при разделении не используются.

## Предобработка

Исходные принятые файлы в raw не редактируются. При загрузке: коррекция EXIF и RGB.
Train: RandomResizedCrop(160, scale=(0.75,1)), RandomHorizontalFlip, ColorJitter(0.15,0.15,0.1,0.03).
Общая детерминированная часть: ImageOps.fit в центральный квадрат 160×160 BICUBIC, деление на 255, mean=(0.485,0.456,0.406), std=(0.229,0.224,0.225), CHW float32.
Эта же функция из app/preprocessing.py применяется к validation, test и в Gradio. Для данных аугментации не создают новые независимые изображения и не увеличивают заявленный объём.

## Ограничения

Метки взяты из названий Commons и проверены визуально на соответствие группе; независимая экспертная проверка вида не выполнялась.
У каждого класса только один вид: модель не обучалась на всех бабочках, стрекозах или божьих коровках.
Поисковый отбор смещён к хорошо подписанным фотографиям. Возможны ошибки каталога, фоновая корреляция и пересечение отдельных источников с ImageNet, на котором обучены исходные веса.
Авторская группировка снижает утечку между нашими частями, но не доказывает отсутствие пересечения с pretrained-данными.
25 тестовых фотографий недостаточно для узкой оценки качества на новых условиях.

## Права

Все авторы, лицензии, их URL и ссылки на фотографии доступны в [ATTRIBUTION.md](ATTRIBUTION.md) и [sources.csv](sources.csv).
Файлы сохраняют исходную лицензию. Изменение — серверное уменьшение; локальные обучающие преобразования не распространяются как отдельные фотографии.
